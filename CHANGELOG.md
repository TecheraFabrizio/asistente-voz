# Changelog

**English** · [Español más abajo](#registro-de-cambios)

## 2026-10-17

### Core
- Voice pipeline: wake word (`go` / `va`), dictation, end word (`done` / `listo`). Whisper small on the GPU, under a second per sentence (measured 0.4 to 0.6 s).
- Saying `go` again restarts the dictation; `cancel` drops it. A stray `done` no longer opens an empty dictation.
- Whisper's prompt echo ("open the page") is filtered out of every transcript.
- **Mixed-language dictation**: long sentences are transcribed with automatic language detection, so English comes out in English and Spanish in Spanish. Short clips (wake and end words) keep the configured language.
- Requests that are only a narration command ("read it to me") are narrated locally instead of being sent to Claude.

### Panel
- Status panel with live state (idle, recording, transcribing), the steps Claude takes (fed by Claude Code hooks), the model and effort in use, and the dictation box.
- **Editable dictation box**: click it, fix the transcript, press Enter to send. Esc releases it. What is in the box is what gets sent.
- Answer panel attached above the status panel: formatted (headings, bullets, bold), scrollable, collapsible, slightly transparent.
- Animated character (Rover, Merlin, Clippy): works while Claude works, celebrates when done, rests when idle. Left-click for a gesture, right-click to switch. Sprites from clippy.js (MIT); the characters themselves belong to Microsoft.
- Stray "ok" / "dale" no longer close the answer panel.

### Language
- `ES | EN` toggle on the panel switches transcription, voice, every UI string, the hook step names, the overlay button and an already-open answer panel. The panel also follows changes made from outside (`python voz/config.py es`).
- English is the default. Spanish with one click.

### Voice
- Neural voices (edge-tts), sentence by sentence; first sentence in about a second. Queue so nothing overlaps; `quiet` / `stop` cuts it; `narrate`, `read it`, `read the text in the modal` start it.
- Offline fallback to the system voice.

### Guided tours
- JSON tours: boxes, arrows, labels and numbers drawn over any application, narrated step by step, erased, next. Click-through on Windows.

### Platforms
- Windows, Linux and macOS. Everything OS-specific lives in `voz/so.py` (beep, processes, audio playback, offline voice, CUDA). Whisper falls back to CPU without an NVIDIA GPU. Linux and macOS are written against their APIs but have not been run there yet.

### Start
- `start.bat` / `start.sh`: one command starts the listener, the panel and Claude Code already watching the voice file, with `--dangerously-skip-permissions` so it is hands-free. No IDE needed.

### Demo
- `demo_asistente.mp4`: 1 min 48 s, narrated in English, generated by driving the real panel and overlay.

# Registro de cambios

## 2026-10-17

### Base
- Flujo de voz: palabra de activación (`va` / `go`), dictado, palabra de cierre (`listo` / `done`). Whisper small en la GPU, menos de un segundo por frase (medido 0,4 a 0,6 s).
- `va` de nuevo reinicia el dictado; `cancelá` lo tira. Un `listo` suelto ya no abre un dictado vacío.
- El eco del prompt de Whisper ("abrí la página") se filtra de toda transcripción.
- **Dictado mixto**: las frases largas se transcriben con detección automática de idioma, así el inglés sale en inglés y el español en español. Los clips cortos (va, listo) mantienen el idioma configurado.
- Si lo dictado es sólo un pedido de narrar ("narrámelo"), se narra acá en vez de mandarse a Claude.

### Panel
- Panel de estado con el estado en vivo (espera, grabando, transcribiendo), los pasos de Claude (vía hooks de Claude Code), modelo y effort en uso, y la caja de dictado.
- **Caja de dictado editable**: click, corregís, Enter manda. Esc la suelta. Lo que hay en la caja es lo que se manda.
- Panel de respuesta pegado arriba: formateado (títulos, viñetas, negritas), con scroll, colapsable, un poco transparente.
- Personaje animado (Rover, Merlin, Clippy): trabaja mientras Claude trabaja, festeja al terminar, descansa en espera. Click izquierdo gesto, click derecho cambia. Sprites de clippy.js (MIT); los personajes son de Microsoft.
- "ok" / "dale" sueltos ya no cierran el panel de respuesta.

### Idioma
- El toggle `ES | EN` cambia transcripción, voz, todos los textos de la interfaz, los nombres de los pasos del hook, el botón del overlay y el panel de respuesta ya abierto. El panel también sigue cambios hechos desde afuera (`python voz/config.py es`).
- Inglés por defecto. Español con un click.

### Voz
- Voces neuronales (edge-tts), frase por frase; la primera en un segundo. Cola para que nada se pise; `callate` la corta; `narralo` la arranca.
- Sin internet cae a la voz del sistema.

### Recorridos guiados
- Recorridos en JSON: recuadros, flechas, carteles y números sobre cualquier aplicación, narrados paso a paso, borrados, siguiente. Los clicks atraviesan el dibujo en Windows.

### Plataformas
- Windows, Linux y macOS. Todo lo del sistema vive en `voz/so.py`. Whisper cae a CPU sin GPU NVIDIA. Linux y macOS están escritos contra sus APIs pero todavía no se corrieron ahí.

### Arranque
- `start.bat` / `start.sh`: un comando arranca escucha, panel y Claude Code vigilando el archivo de voz, con `--dangerously-skip-permissions` para que sea manos libres. Sin IDE.

### Demo
- `demo_asistente.mp4`: 1 min 48 s, narrado en inglés, generado manejando el panel y el overlay reales.
